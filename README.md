# 쿠피 (Coupi)

Gmail 계정에 도착하는 쿠폰/프로모션 메일을 실시간으로 감지하고, 실제로 사용 가능한 쿠폰인지 판별해 모바일 푸시 알림으로 전달하는 앱.

## 현재 상태

- 설계 단계 (개발 착수 전)
- 메일 제공자 범위: **Gmail 단독** (네이버 메일은 지원하지 않음 — 사유는 `docs/00-개요.md` 참고)
- 지금 무엇을 해야 하는지는 [`PROGRESS.md`](./PROGRESS.md)의 "0단계 — 착수 전 블로커 해결"부터 확인할 것

## 시작하기 전에

`PROGRESS.md`의 "0단계"에 정리된 착수 전 결정 사항(LLM 벤더 선택, 다중 디바이스 정책 등)을 먼저 확정한 뒤 개발을 시작한다. 각 설계 문서 상단에 "범위 변경" 표시가 있는 부분은 최초 설계 이후 바뀐 내용이니 주의해서 볼 것.

## 기술 스택 (요약)

- 백엔드: Node.js (NestJS), PostgreSQL, Redis(BullMQ)
- 모바일: React Native
- 메일 연동: Gmail API (OAuth 2.0, Pub/Sub push)
- 쿠폰 판별: 규칙 필터 + LLM 구조화 출력
- 푸시: FCM (Android), FCM 경유 APNs (iOS)
