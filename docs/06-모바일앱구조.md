# 06. 모바일 앱 구조 상세 설계

> **범위 변경 (2026-09-21)**: Gmail 단독 지원으로 한정됨에 따라 메일 서비스 선택 화면 및 네이버 온보딩 플로우를 제거했다 (`00-개요.md` 참고).

원본 설계의 "모바일 앱 구조 설계" 섹션을 화면 단위/상태 관리 수준까지 구체화한다.

## 기술 스택 제안

- React Native (원본 설계 유지) + TypeScript
- 상태 관리: React Query(서버 상태, 쿠폰 목록/상세 캐싱·재검증) + 가벼운 클라이언트 상태는 Zustand
- 네비게이션: React Navigation (Stack + Bottom Tab)
- 푸시: `@react-native-firebase/messaging`

## 화면별 상세

### 1. 온보딩
- 1-1. 인트로 슬라이드 (앱 소개, 3장 이내)
- 1-2. 권한 안내 화면 — "읽기 전용으로만 접근하며 메일 본문은 서버에 저장하지 않습니다" 명시 (개인정보 신뢰 확보 목적, 원본 설계의 개인정보 원칙을 UI에 반영)
- 1-3. Gmail OAuth 웹뷰 → 콜백 딥링크로 앱 복귀
- 1-4. 연결 완료 화면 → 쿠폰 목록으로 이동

메일 서비스 선택 화면은 두지 않는다 (Gmail 단독 지원이므로 선택지 자체가 없음). Gmail 외 메일 서비스를 지원할지에 대한 안내 문구 노출 여부는 `00-개요.md` Open Question #5(신규) 참고.

### 2. 쿠폰 목록 (홈)
- 상태별 탭 또는 필터: 사용 가능 / 만료 임박(D-3 이내) / 지난 쿠폰
- 카드 구성: 브랜드명(발신자 기반), 할인율, D-day 배지, 조건 요약 한 줄
- Pull-to-refresh로 수동 갱신 지원 (푸시를 못 받았을 경우 대비)
- 빈 상태(Empty state): "아직 도착한 쿠폰이 없어요 + 메일 연결 상태 확인" 안내

### 3. 쿠폰 상세
- 할인율, 쿠폰 코드(있는 경우 복사 버튼), 조건, 만료일
- "원본 메일 보기" 버튼 → 메일 앱으로 딥링크 (본문을 앱에 저장하지 않으므로 원문은 항상 메일 제공자 링크로 연결)
- "사용 완료로 표시" / "숨기기" 액션 (00번 문서 Open Question #4 대응, `PATCH /coupons/:id`)
- 베타 단계: "이 쿠폰 정보가 정확한가요?" 피드백 버튼 (`POST /coupons/:id/feedback`)

### 4. 설정
- 연결된 메일 계정 목록 + 계정별 연결 해제
- 알림 설정: 신규 쿠폰 알림 / 만료 임박 리마인더 개별 토글 (04번 문서 기준)
- 계정 삭제/로그아웃

## 상태 관리 및 데이터 흐름

- 앱 실행 시 React Query가 `/coupons` 를 fetch, 포그라운드 복귀 시 자동 재검증(`refetchOnAppStateChange`)
- 푸시 알림 수신 시(포그라운드/백그라운드 모두) 해당 `couponId`로 캐시 무효화 → 목록/상세 화면이 열려 있다면 최신 데이터로 갱신

## 백그라운드 푸시 처리 상세

- **포그라운드**: `messaging().onMessage()`로 수신, 인앱 배너(토스트) 형태로 표시 + React Query 캐시 갱신
- **백그라운드/종료 상태**: OS가 알림 표시 담당 (원본 설계와 동일), 사용자가 탭하면 `messaging().onNotificationOpenedApp()` / `getInitialNotification()`으로 `data.deeplink` 파싱 후 해당 쿠폰 상세로 이동
- **iOS 알림 권한**: 온보딩 완료 직후(메일 연결 성공 시점)에 권한 요청 — 앱 실행 즉시 요청하면 거부율이 높으므로 가치를 먼저 보여준 뒤 요청하는 순서 권장

## 딥링크 스킴

- `myapp://coupons/:id` — 쿠폰 상세
- `myapp://settings` — 설정 화면 (향후 이메일 재인증 유도 등에 활용)

## 에러/엣지케이스 UI (08번 문서와 연결)

- 메일 계정 `status='reauth_required'` 또는 `'auth_failed'`일 때 홈 화면 상단에 배너로 "메일 연결을 다시 확인해주세요" 노출 + 탭 시 재인증 플로우로 이동
- 네트워크 오류 시 React Query의 캐시된 마지막 데이터를 우선 표시 + 재시도 버튼
